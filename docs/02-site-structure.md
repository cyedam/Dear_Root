# Dear Root 사이트 구성

> 기준 문서: 01-site-purpose.md

## 1. 확정한 내용

### 방문자 흐름별 구성

| 방문자 행동 | 필요한 정보·기능 | 배치할 페이지 / 섹션 | 다음 행동 |
|---|---|---|---|
| 사이트에 처음 들어옴 | 어떤 브랜드인지 한눈에 알기 (목적 문장), 몰라도 괜찮다는 다정한 첫인상 | ① 메인: 브랜드 소개 섹션 | 맞춤 케어 체험 시작 / 케어 제품 바로 보기 |
| 체험 시작 | 실내 화분 식물의 종류와 지금 상태 입력하기 | ② 맞춤 케어 체험: 진단 단계 | 결과 보기 |
| 결과 확인 | 시드는 원인, 내 식물에 맞는 흙·영양제, 살릴 수 있다는 안심 문구 | ② 맞춤 케어 체험: 결과 섹션 | 케어 제품 구매 / 케어 가이드 보기 |
| 결과에서 바로 구매 | 추천된 세트 또는 개별 상품을 고르는 간단한 구매 버튼 (결과 내용보다 뒤에 배치) | ② 맞춤 케어 체험: 결과 섹션 하단 | 구매 진행 / 상세 보기 |
| 상품 자세히 보기 | 흙과 영양제의 상세 내용, 세트 구매와 개별 구매 | ③ 케어 제품 페이지 | 구매 진행 / 맞춤 케어 체험 시작 |
| 체험 없이 상품 보기 | 원하는 상품을 바로 찾아 고르기 | ③ 케어 제품 페이지 (메인에서 바로 이동) | 구매 진행 / 맞춤 케어 체험 시작 |
| 돌보는 법 알아보기 | 물 주기, 햇빛, 분갈이 관리 요령 | ④ 케어 가이드 | 맞춤 케어 체험 시작 |

### 페이지 구분

1. **메인**: 브랜드 소개, 체험 시작과 케어 제품으로 가는 두 갈래 진입점
2. **맞춤 케어 체험**: 진단 → 결과 → 간단 구매 버튼
3. **케어 제품**: 상품 상세, 세트·개별 구매 (체험 결과에서도, 메인에서도 들어옴)
4. **케어 가이드**: 돌보는 방법

### 결정한 선택 사항

- **케어 제품 배치:** 체험 결과 안에는 간단한 구매 버튼을 두고, 별도 케어 제품 페이지에는 상세 내용을 둡니다.
- **체험 없이 상품 보기:** 허용합니다.
- **체험으로 돌아오는 경로:** 메인과 케어 제품 페이지에 체험 시작 버튼을 함께 보여 줍니다.
- **상단 메뉴:** 로고(메인으로), 맞춤 케어 체험, 케어 제품, 케어 가이드. 로고는 왼쪽, 메뉴 3개는 가운데, 장바구니 아이콘 자리는 오른쪽에 둡니다. 메인에서도 상단 메뉴로 케어 가이드에 바로 갈 수 있습니다. 장바구니 아이콘 자리는 추후 결정입니다.
- **구매 범위:** 지금은 구매 버튼까지만 만듭니다. 장바구니·결제는 시간이 남으면 추가합니다.
- **안심과 확신:** 체험 결과의 안심 문구에 더해, 메인 브랜드 소개 섹션의 말투도 '몰라도 괜찮다'는 안심을 주는 역할을 맡습니다.
- **체험 진단 기준:** 식물 종류 → 증상 → 환경(햇빛·물 주기 습관) 3단계로 나눕니다.
- **케어 제품 페이지:** 하위 페이지 없이 목록 한 페이지에서 세트 상품과 개별 상품(흙, 영양제)을 모두 봅니다. DIY 흙 만들기 섹션도 이 페이지에 둡니다.
- **체험 질문:** 3단계 7문항, 일러스트 카드형으로 확정했습니다. 자세한 내용은 99-care-quiz.md에 있습니다.
- **벌레:** 관련 상품은 팔지 않고 관리법만 안내합니다.
- **메인 히어로:** 브랜드 소개는 히어로 섹션으로 씁니다. 실사 식물이 화면 전체를 채우고, 잎이 마우스를 가까이 따라 바람에 흔들리는 인터랙티브 장면 위에 목적 문장과 체험 시작 버튼을 올립니다. GNB는 투명하게 장면 위에 겹칩니다. 터치 기기와 '동작 줄이기' 설정에서는 멈춘 장면을 보여 줍니다. 히어로 앞에 로딩 화면은 두지 않습니다. (레퍼런스: 05-site-reference.md)
- **메인 두 번째 섹션:** 체험 시작은 히어로에 있으므로, 아래는 히어로에서 이어지는 실사 스크롤 장면 두 개로 둡니다. 조금 내리면 배경이 최소한으로 아래로 움직여 흙이 보이고 '케어 제품 바로가기'가, 더 내리면 배경이 최소한으로 위로 움직여 햇빛이 드는 장면과 '케어 가이드 보기'가 차례로 나타납니다.
- **그림체:** 메인 히어로와 이어지는 흙 · 햇빛 장면은 실사, 그 외 화면은 라인 일러스트에 최소한의 포인트 색을 씁니다.
- **메뉴·페이지 이름:** '케어 세트' 대신 '케어 제품'을 씁니다. 세트만 있는 게 아니기 때문입니다.
- **체험 결과의 버튼:** 'DIY 흙 담기'와 '제품 구매하기' 두 갈래로 나눕니다.
- **케어 제품 페이지 순서:** DIY 흙 만들기를 맨 위에 둡니다. 맞춤 케어 다음가는 두 번째 아이덴티티입니다.
- **케어 가이드 Q&A:** 가이드를 읽어도 모르겠는 사람을 위해 맨 아래쪽에 자주 묻는 질문과 질문 남기기 창을 둡니다. 답변 방식은 추후 결정입니다.
- **케어 가이드 페이지:** 한 페이지 안에 물 주기 / 햇빛 / 분갈이 섹션으로 나눕니다. 식물 종류에 따라 요령이 다르므로, 각 섹션은 공통 요령 아래에 '식물 종류별로 보기'(펼침 · 접힘)를 두고 체험 Q1과 같은 6종(관엽 · 다육·선인장 · 꽃 피는 식물 · 허브 · 과실 · 난초류)의 차이를 보여 줍니다. 벌레 대처와 Q&A는 공통입니다.

## 2. 추후 결정으로 남긴 것

- 결과 화면의 구성
- 구매 진행 방식 (장바구니, 결제, 주문 확인) — 시간이 남으면 진행
- 반응형 대응 범위 (데스크탑 기준은 확정, 다른 화면 크기 범위는 추후 결정)
