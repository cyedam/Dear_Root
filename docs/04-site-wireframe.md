### P1-S1 히어로
※ 실사 식물이 화면을 채우고, 잎이 마우스를 가까이 따라 흔들림. 터치 기기·동작 줄이기에서는 멈춘 장면

- 실사 인터랙티브 장면 (화면 전체, 어두운 X 상자 + ◎ 배지) · 잎이 마우스를 따라 바람에 흔들림, 그 위에:
  - 세로 묶음
    - 제목: **잎이 보내는 신호를 읽고**
    - 제목: **뿌리부터 다시 돌봐요**
  - 세로 묶음
    - 문구: "식물이 왜 시드는지 몰라도 괜찮아요. / 몇 가지 질문에 답하면 내 식물에 맞는 케어를 같이 찾아 드릴게요."
    - 버튼 **P1-B1** "맞춤 케어 체험 시작" (핵심 행동)
- 움직임
  - 식물을 앞 · 중간 · 뒤 여러 겹으로 나누고, 앞 잎은 크게, 뒤 잎은 작게 흔들림
  - 잎이 마우스를 **가까이** 따라옴 (늦게 따라오는 느낌을 최소화)
  - 마우스가 멈추거나 화면을 벗어나면 잎이 천천히 제자리로
  - 장면을 불러오지 못해도 정지 이미지와 목적 문장, 체험 시작 버튼은 바로 보임

### P1-S2 스크롤 장면
※ 히어로에서 이어지는 실사 장면. 스크롤하면 배경이 최소한으로 아래로(흙) → 위로(햇빛) 움직이며 두 장면이 차례로 나타남. 두 장면 모두 문구와 버튼은 **왼쪽 정렬, 화면 왼쪽 세로 가운데**에 둠

**장면 ① 흙** (어두운 X 상자 + ↓ 배지 · 배경이 최소한으로 아래로, 화분 속 흙과 뿌리가 보임)
- 세로 묶음 (왼쪽 정렬, 왼쪽 세로 가운데)
  - 제목: **케어 제품**
  - 문구: "내 식물에 맞는 흙과 영양제를 고르거나, / 재료를 직접 섞어 나만의 흙을 만들어 보세요."
  - 버튼 **P1-B2** "케어 제품 바로가기"

**장면 ② 햇빛** (어두운 X 상자 + ↑ 배지 · 배경이 최소한으로 위로, 잎 위로 햇빛이 듦)
- 세로 묶음 (왼쪽 정렬, 왼쪽 세로 가운데)
  - 제목: **케어 가이드**
  - 문구: "물 주기, 햇빛, 분갈이, 벌레 대처까지. / 처음 키우는 분도 따라 하기 쉽게 정리했어요."
  - 버튼 **P1-B3** "케어 가이드 보기"

- 움직임
  - 배경은 흙과 햇빛이 보일 만큼만 **최소한으로** 움직임
  - 배경 위치만 크게 옮기지 않고, 흙과 햇빛은 그 자리에서 서서히 드러나게 해 장면이 어색하게 끊기지 않게 함 (05 문서 추천안)

### P2-S1 진행 표시
※ 3단계 7문항 중 현재 위치

- 진행 표시: 단계 이름 1 식물 종류 · 2 증상·벌레 · 3 환경, 진행 막대, "1 / 7"

### P2-S2 질문 카드
※ 일러스트 카드. 예시는 Q1. 단일 선택은 카드를 누르면 다음 질문, 증상·벌레(Q2·Q3)는 다중 선택

- 제목: **어떤 식물을 키우고 계세요?**
- 문구: "가장 비슷한 카드를 골라 주세요. 잘 몰라도 괜찮아요."
- 단일 선택(○) 카드 7장 (4열, 이미지 X 상자 + 문구) (핵심 행동)
  - **관엽식물** — 잎을 보며 키우는 초록 식물
  - **다육·선인장** — 잎이나 줄기가 통통한 식물
  - **꽃 피는 식물** — 꽃을 보기 위해 키우는 식물
  - **허브** — 향이 나고 잎을 쓰기도 하는 식물
  - **과실 식물** — 열매가 열리는 식물
  - **난초류** — 흙 대신 바크·수태에 심는 식물
  - **잘 모르겠어요** — 관엽식물 기준으로 함께 볼게요

### P2-S3 질문 이동
※ '다음'은 다중 선택 질문에서만 표시

- 가로 배치
  - 버튼 **P2-B1** "이전 질문"
  - 버튼 **P2-B2** "다음" (핵심 행동)

### P2-S4 결과 요약
※ 7문항을 마치면 표시. 예시는 과습이 주원인인 경우. 주원인 일러스트 + 원인·해결책 문구

- 가로 배치
  - 이미지 X 상자 · 주원인 일러스트
  - 세로 묶음
    - 라벨: "진단 결과"
    - 제목: **물이 조금 많았어요**
    - 문구: "흙이 오래 젖어 있으면 뿌리가 숨 쉬기 어려워져요. 잎이 노랗게 변한 건 뿌리가 쉴 틈이 필요하다는 신호예요."
    - 회색 상자
      - 제목: **가장 먼저 할 일**
      - 문구: "겉흙이 손가락 한 마디 깊이까지 마를 때까지 물 주기를 잠시 쉬어 주세요."
    - 강조 문구: "조금만 바꿔 주면 다시 건강하게 자랄 거예요."

### P2-S5 다른 원인 · 벌레 대처
※ 다중 선택 시 나머지 원인, 벌레를 고르면 대처법 표시

- 제목: **함께 살펴보면 좋아요**
- 목록 3줄 (작은 이미지 X 상자 + 제목 + 설명)
  - **햇빛이 조금 부족해요** — 밝지만 해가 직접 들지 않는 창가 쪽으로 옮겨 주세요.
  - **뿌리파리가 보여요** — 식물을 키우다 보면 벌레가 찾아오는 건 자연스러운 일이에요. 겉흙을 말리고 노란 끈끈이 트랩을 꽂아 주세요.
  - **화분이 작아졌어요** — 봄이나 가을에 한 치수 큰 화분으로 옮겨 주면 뿌리가 편해져요.

### P2-S6 추천 케어
※ 추천 흙·영양제. 상품이 필요 없는 원인은 관리법만 표시. 버튼은 결과 내용 뒤에 배치. 가격은 추후 결정

- 제목: **내 식물을 위한 추천 케어**
- 상품 카드 2장 (2열, 이미지 X 상자 + 문구)
  - **배수 잘 되는 흙** — 물이 고이지 않게 흙 사이에 숨구멍을 만들어 줘요. · 00,000원
  - **뿌리 활력제** — 지친 뿌리가 다시 힘을 내도록 도와줘요. · 00,000원
- 가로 배치
  - 버튼 **P2-B3** "DIY 흙 담기"
  - 버튼 **P2-B4** "제품 구매하기"

### P3-S1 DIY 흙 만들기
※ 두 번째 아이덴티티라 맨 위에 배치. 재료 카드마다 − / + 로 스쿱 수를 정함(카드를 누르면 1스쿱 더). 1스쿱 0.6L, 한 봉 6L = 합계 10스쿱. 담을 때마다 결과 갱신. 예시는 배수 재료를 많이 담은 경우(상토 2 · 펄라이트 2 · 마사토 1 · 바크 1 = 6스쿱)

- 제목: **나만의 흙 만들기**
- 문구: "재료를 한 스쿱씩 담아 보세요. 담을 때마다 이 흙이 어떤 식물에 잘 맞는지 바로 알려 드려요."
- 가로 배치
  - 세로 묶음
    - 라벨: "재료 고르기 · 한 봉 6L, 1스쿱 0.6L"
    - 다중 선택(□) 카드 8장 (4열, 이미지 X 상자 + 이름 + 설명 + 수량 조절)
      - 카드 아래 수량 조절: 버튼 **P3-B7** "−"(이 재료 한 스쿱 빼기) · 담은 수 "n 스쿱" · 버튼 **P3-B8** "+"(이 재료 한 스쿱 더) · 카드마다 같은 버튼
      - 1스쿱 이상 담은 재료는 선택 표시(□ 채움 + 카드 테두리 강조)
      - **상토** — 영양과 보습을 함께 · 예시 2 스쿱
      - **부엽토** — 양분이 많아요 · 0 스쿱
      - **코코피트** — 물을 오래 머금어요 · 0 스쿱
      - **질석** — 물과 양분을 붙잡아요 · 0 스쿱
