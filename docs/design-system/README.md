# Dear Root 디자인 시스템

잎이 보내는 신호를 읽고 뿌리부터 다시 돌보는 맞춤 식물 케어, **Dear Root**의 화면 규칙입니다. 지금 만들어진 P1(메인) · P2(맞춤 케어 체험 · 결과) · P3(케어 제품) 디자인에서 실제로 쓰인 값을 모으고, 기획 문서 06(색상) · 07(글꼴) · 97(색상, 06과 같은 내용) · 98(일러스트 스타일)을 하나로 합쳤습니다.

> 색 이름, 글꼴, 값은 모두 `tokens.json`에 있습니다. 화면을 만들 때는 값 대신 토큰 이름(`--leaf-green`, `--radius-xl` 등)을 씁니다.

## 1. 브랜드 성격

- **다정하고 편안하게.** 병원 같은 차가움을 피합니다. "몰라도 괜찮아요", "같이 찾아 드릴게요"처럼 옆에서 말해 주는 말투.
- **차분하고 신선하게.** 순백 바탕 + 연두 강조(라임 화이트). 크림 · 짙은 갈색처럼 빈티지하고 무거운 조합은 쓰지 않습니다.
- **판매 압박 없이.** 체험이 먼저, 구매는 늘 내용 뒤에, 덜 눈에 띄게.
- **흙이 주인공.** 사이트 전체는 화이트 · 라임, 흙과 관련된 곳에만 샌드를 꾸준히 써서 주력 제품이 흙임을 보여 줍니다.

## 2. 글쓰기 (말투)

| 이렇게 | 이렇게 쓰지 않기 |
|---|---|
| 물이 조금 많았어요 | 과습 진단 |
| 겉흙이 마를 때까지 물 주기를 잠시 쉬어 주세요. | 급수를 중단하십시오. |
| 식물을 키우다 보면 벌레가 찾아오는 건 자연스러운 일이에요. | 해충 발생! |
| 잘 모르겠어요 → 관엽식물 기준으로 함께 볼게요 | 선택하지 않으면 진행할 수 없습니다 |

- 해요체, 짧은 문장, 전문 용어는 쉬운 말로 풀어 씁니다(배수 → "물이 잘 빠져요").
- 결과는 **원인 → 할 일 → 추천 케어** 순서. 마지막은 안심 문장("조금만 바꿔 주면 다시 건강하게 자랄 거예요.")으로 닫습니다.
- 버튼은 행동을 말합니다: 맞춤 케어 체험 시작, 다음, 이전 질문, 다시 담기, 이 배합으로 구매.
- 느낌표 · 이모지는 쓰지 않습니다.

## 3. 색 — 라임 화이트 (06 · 97)

| 역할 | 토큰 | 값 | 쓰는 곳 |
|---|---|---|---|
| 배경 | `white` | #FFFFFF | 페이지 기본 배경 |
| 섹션 배경 | `pale-lime` | #F2F8E6 | 섹션 구분, 결과 상자, 일러스트 자리 |
| 주요 색 | `leaf-green` | #2E7D4F | 핵심 버튼, 링크, 선택 테두리, 강조 글자 |
| 강조 | `lime` | #C6E07A | 진행 막대, 선택 표시, 배지 (면으로만) |
| 흙 포인트 | `sand` | #CDB394 | 흙 상품 · DIY 재료 · 화분 층 (면으로만) |
| 본문 글자 | `ink` | #1F2A22 | 제목, 본문 |

화면에서 더 쓰인 색: `hero-lime` #EAF3DC(히어로), `sun-tint` #FBFCF4(햇빛 장면), `ink-soft` #2F3D33(연두 배경 위 설명), `ink-muted` #4A574E(보조 글자), `line` #E4ECD8 · `line-strong` #DCE6CF(선), hover용 `leaf-green-hover` #276B43 · `leaf-green-deep` #256A42.

**규칙**

- 주요 버튼: `leaf-green` 바탕 + 흰 글자(5.05:1).
- `lime` · `sand`는 **글자색으로 쓰지 않습니다.** 면(배경 · 막대 · 배지)으로만. 라임 배지 위 글자는 `leaf-green`, 샌드 배지 위 글자는 `soil-ink` #5E4A33.
- 페일 라임 위 글자: 본문 `ink`(설명은 `ink-soft`), 강조 `leaf-green`.
- 섹션은 선 대신 `white` ↔ `pale-lime`를 번갈아 구분합니다.
- 흙 색(`sand`, `soil-*`)은 흙과 관련된 곳에만.

### 확인 필요 — 글자 대비

화면에 그대로 쓰인 조합 중 작은 글자(14~16px) 기준 4.5:1에 못 미치는 곳이 있습니다. 값은 바꾸지 않고 표시만 해 두었습니다.

| 조합 | 대비 | 쓰인 곳 | 바꾼다면 |
|---|---|---|---|
| `leaf-green` 글자 / `lime` 바탕 | 3.45:1 | 진단 결과 · 영양제 · 계절 배지 (14px 600) | 글자를 #1F5C39(5.4:1) 또는 `ink`(10.2:1)로 |
| `soil-ink` 글자 / `sand` 바탕 | 4.18:1 | 흙 배지 · 상품 일러스트 자리 | 글자를 #4A3A28(5.4:1)로 |
| `ink-faint` 글자 / `white` | 3.08:1 | '0 스쿱' | #6B776F(4.7:1)로, 또는 `ink-muted` |

### 아직 정하지 않은 것 (06 · 07의 '추후 결정')

- 실사 히어로 사진 위 글자 · 버튼 색 — 사진을 보고 결정 (05-site-reference.md)
- 오류 · 안내 메시지 색
- 회사 정보 · 고객 문의 영역 (푸터의 점선 자리)

## 4. 글꼴 (07)

| 역할 | 글꼴 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| 제목 | 학교안심 뜀틀 (KERIS) | 400 한 가지 | 히어로 · 섹션 · 질문 · 결과 제목 |
| 본문 · UI | 프리텐다드 | 400 본문 / 500 버튼 · 메뉴 / 600 작은 제목 · 가격 · 배지 | 그 밖의 모든 글자 |
| 로고 | Outfit | 600 | 'Dear Root' 워드마크에만 |

- 셋 다 OFL, 웹 임베딩 가능. 폰트 파일은 `fonts/`에 있습니다.
- **뜀틀은 제목에만.** 굵기가 하나뿐인 장식체라 긴 문장 · 작은 글씨 · 버튼 · 가격에는 쓰지 않습니다.
- 가짜 굵게(`font-weight: bold`)를 쓰지 않습니다. 강조는 크기와 `leaf-green`으로.
- 모든 화면에 `word-break: keep-all`.

| 스타일 | 크기 / 줄 간격 | 예 |
|---|---|---|
| `display-hero` | 60 / 1.3, 자간 -0.01em | 히어로 제목 |
| `display-1` | 44 / 1.3 | 어떤 식물을 키우고 계세요? |
| `display-2` | 32 / 1.3 | 함께 살펴보면 좋아요 |
| `display-3` | 26 / 1.4 | DIY 흙 결과 문장 |
| `title-lg` · `title-md` · `title-sm` | 24 · 20 · 18 / 600 | 상품명, 가장 먼저 할 일, 카드 이름 |
| `body-lg` · `body` · `body-sm` | 20 · 18 · 16 / 1.7 | 설명 문단 |
| `button-lg` · `button` | 18 · 16 / 500 | 버튼 |
| `label` · `caption` | 14 / 600 · 400 | 배지, 보조 설명 |

## 5. 레이아웃

- 화면 폭 1440 기준, 좌우 여백 `page-gutter` 120 → 내용 폭 1200.
- 섹션 위아래 `section-top` 96 / `section-bottom` 112. 기본 단위 8px.
- **한 화면에 한 메시지:** 제목 → 설명 → 버튼을 세로 한 묶음으로, 묶음 안 16~32, 버튼 앞 40.
- 카드 그리드: 4열(선택 카드 · 재료 · 개별 상품), 3열(세트), 2열(추천 케어), 간격 24.
- 결과 화면: 원인 → 할 일 → 추천 케어, 구매 버튼은 항상 내용 뒤.

## 6. 모양 · 깊이

- 모서리: 버튼 · 배지 · 막대 `radius-pill`, 카드 · 상자 `radius-xl` 20, 카드 안 이미지 `radius-lg` 16, 탭 · 입력창 `radius-md` 12.
- 그림자는 세 가지 의미만: 핵심 행동(`shadow-cta`), 선택됨(`shadow-selected`), 사진 위 버튼(`shadow-scene`). 카드 hover는 위로 2px + `shadow-hover`.
- 선은 1px `line`. 선택 카드는 2px `leaf-green`, 선택 전은 2px `line`.

## 7. 움직임

- 버튼 · 카드: 0.2s ease. 누르면 `scale(0.98)`(DIY 담기 0.96~0.97).
- 등장: 아래에서 16px 올라오며 0.45s `cubic-bezier(.2,.8,.2,1)`, 순서대로 0.2s씩 늦게.
- 막대 채움: width 0.4~0.45s 같은 곡선.
- P1 장면: 스크롤에 따라 배경이 아주 조금(±28px) 움직이고, 히어로 잎은 마우스를 따라 앞 잎 크게 · 뒤 잎 작게 흔들립니다.
- `prefers-reduced-motion`에서는 모두 끕니다.

## 8. 로고

- 원 안에 두 잎(신호를 보내는 잎: `lime`, `white`)과 아래 세 갈래 뿌리(`sand`) — 바탕 원은 `leaf-green`.
- 워드마크 'Dear Root'는 Outfit 600. GNB · 푸터에서 마크 34px + 간격 10 + 워드마크 22px.
- 파일: Assets › Logos (마크, 가로형 로고, 워드마크).

## 9. 일러스트 (98)

오가닉 플랫 벡터. 둥글고 살짝 비대칭인 큰 면, 외곽선 없음, 그라데이션 · 그림자 · 질감 없음, 한 그림에 3~6색. 자세한 규칙과 생성 프롬프트는 **일러스트 스타일** 섹션에 있습니다.

- 아직 그림이 없는 곳은 점선 자리(`pale-lime` + 1px dashed `placeholder-line`, 흙 상품은 `sand`)로 둡니다 — 컴포넌트 **Placeholder** 참고.
- 사진이 들어갈 자리는 '실사 장면 자리' 칩으로 표시합니다.

## 10. 아이콘

아이콘 세트는 따로 없습니다. 화면에 쓰인 건 화살표 두 개(→ 다음 · 바로가기, ← 이전 질문)뿐이며 24 격자, 선 2, 둥근 끝, 버튼 글자색과 같은 색으로 18~20px에 씁니다.

## 11. 컴포넌트

Button, Badge, QuizProgress, ChoiceCard, ResultSummary, CauseItem, ProductCard, Tabs, MaterialCard, SoilMeter, SceneLabel, Placeholder, Header, Footer. 각 컴포넌트의 미리보기와 쓰는 법은 Components에 있습니다. 모두 토큰 CSS 변수만으로 그려져 있어 그대로 옮겨 쓸 수 있습니다.
