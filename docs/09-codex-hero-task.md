## 0. 한 줄 목표

`hero-demo.html`의 동작(마우스 바람 → 식물이 휨, 스크롤 두 칸 → 흙 · 햇빛)을 **three.js + 실사 식물 이미지**로 React 컴포넌트에 옮긴다.

## 1. 결과물

```
src/

    HeroScene/
      HeroScene.jsx        ← 섹션 + 글 · 버튼 (DOM) + 캔버스
      HeroScene.css

      config.js            ← 조절값 (아래 6번)
  assets/
```

- 실사 이미지가 아직 없으면 **캔버스로 그린 임시 잎 텍스처**를 만들어 같은 구조로 돌아가게 할 것 (이미지 파일만 넣으면 바로 바뀌게).

## 2. 화면 구성 (DOM)

- 섹션 높이 `300vh`, 안쪽 무대는 `position: sticky; top: 0; height: 100vh`.
- 캔버스는 무대 전체. 글 · 버튼 · GNB는 캔버스 **위의 DOM**으로 둔다 (캔버스에 글을 그리지 않음).
- 장면 1 히어로 (가운데 정렬): 제목 "잎이 보내는 신호를 읽고 / 뿌리부터 다시 돌봐요"(위에서 200px), 문구 "식물이 왜 시드는지 몰라도 괜찮아요. / 몇 가지 질문에 답하면 내 식물에 맞는 케어를 같이 찾아 드릴게요." + 버튼 "맞춤 케어 체험 시작"(아래에서 96px). 버튼 → 맞춤 케어 체험 페이지.
- 장면 2 흙 (왼쪽 정렬, 화면 왼쪽 세로 가운데): 제목 "케어 제품" / 문구 "내 식물에 맞는 흙과 영양제를 고르거나, / 재료를 직접 섞어 나만의 흙을 만들어 보세요." / 버튼 "케어 제품 바로가기 →" → 케어 제품 페이지.
- 장면 3 햇빛 (장면 2와 같은 배치): 제목 "케어 가이드" / 문구 "물 주기, 햇빛, 분갈이, 벌레 대처까지. / 처음 키우는 분도 따라 하기 쉽게 정리했어요." / 버튼 "케어 가이드 보기 →" → 케어 가이드 페이지.
- 글은 스크롤에 맞춰 서서히 나타나고 사라짐 (16px 올라오며, `cubic-bezier(.2,.8,.2,1)`).
- 색 · 글꼴: 배경 `#EAF3DC`, 글자 `#1F2A22`, 설명 `#2F3D33`, 주요 버튼 `#2E7D4F`(hover `#276B43`) + 흰 글자 + `0 8px 24px rgba(46,125,79,.22)`, 장면 위 버튼은 흰 바탕. 제목 글꼴 '학교안심 뜀틀'(SchoolSafeVaultingBox), 본문 프리텐다드. 버튼 260×56, 둥근 모서리 999px.
- **로딩 화면을 두지 않는다.** 장면이 준비되기 전에도 글과 버튼은 바로 보인다.

## 3. 장면 구조 (three.js)

- `OrthographicCamera` (픽셀 단위로 맞춤: 화면 1px = 장면 1단위), 투명 배경 렌더러, `devicePixelRatio`는 최대 2.
- 그리는 순서(뒤 → 앞): 햇빛 겹 → 식물 뒤 겹 → 중간 겹 → 앞 겹 → 흙 겹.
- **식물 3겹** = 겹마다 `InstancedMesh` 1개 (그리기 호출 겹당 1번).
  - 기하: `PlaneGeometry(1, 1, 1, 16)` — 세로 16칸, **원점을 밑동(아래 가운데)** 으로 옮김 (`translate(0, 0.5, 0)`).
  - 식물 이미지는 **텍스처 아틀라스 1장**에 모으고(최대 4096²), 인스턴스마다 `aUvRect`(x, y, w, h)로 자기 칸을 씀.
  - 인스턴스 속성: `aUvRect`, `aBend`(매 프레임 갱신), `aFlip`(좌우 반전 ±1), `aTint`(뒤 겹 색 섞기).
  - 위치 · 크기 · 좌우는 `instanceMatrix`로.
- 겹 설정 (시연과 같음):

| 겹 | 개수(1440px 기준) | 크기 배율 | 불투명도 | 바람 반응 | 따라오는 빠르기 |
|---|---|---|---|---|---|
| 뒤 | 약 70 | 0.55~0.85 | 0.55 (또는 미리 흐린 이미지) | 0.4 | 0.06 |
| 중간 | 약 100 | 0.8~1.1 | 0.85 | 0.7 | 0.09 |
| 앞 | 약 70 | 1.05~1.5 | 1 | 1.0 | 0.12 |

- 밑동 높이: 화면 높이의 86% 근처(±5%), 뒤 겹일수록 조금 위.
- **글 뒤는 식물 키를 낮춤** (시연과 같음): 중간 · 앞 겹에서 화면 왼쪽 38% 안쪽은 끝이 화면 높이 60%보다 위로 못 올라가게, 가운데 ±30%는 48%까지. 뒤 겹은 30%까지.
- 시연의 가운데 비우기 규칙도 유지: 중간 · 앞 겹의 가운데 28% 구간은 70% 확률로 건너뜀.

### 3-1. 식물 셰이더 (휘기)

```glsl
// vertex (요지)
float t = uv.y;                      // 0 = 밑동, 1 = 끝
float k = pow(t, 1.6);               // 위로 갈수록 많이 휨
vec3 p = position;
p.x += sin(aBend) * k * 0.9;         // 기하는 높이 1 기준 → instanceMatrix가 크기 적용
p.y *= 1.0 - 0.18 * abs(sin(aBend)) * k;
// 아주 약한 잎 떨림 (선택): p.x += sin(uTime*6.0 + t*8.0 + aPhase) * 0.004 * k * uWind;
vUv = vec2(mix(aUvRect.x, aUvRect.x + aUvRect.z, aFlip > 0.0 ? uv.x : 1.0 - uv.x),
           aUvRect.y + uv.y * aUvRect.w);
```

```glsl
// fragment (요지)
vec4 c = texture2D(uAtlas, vUv);
if (c.a < 0.02) discard;
c.rgb = mix(c.rgb, uHazeColor, aTint);   // 뒤 겹을 배경색 쪽으로 살짝
gl_FragColor = vec4(c.rgb, c.a * uLayerOpacity);  // premultipliedAlpha 주의
```

- 텍스처는 `premultiplyAlpha`와 블렌딩을 맞춰 가장자리 흰 테두리(헤일로)가 생기지 않게 할 것. `colorSpace = SRGBColorSpace`, 밉맵 사용.

## 4. 바람 (wind.js) — 시연 코드와 같은 방식

1. **따라오는 두 점** (Codrops 방식): `p0 += (mouse - p0) * 0.12`, `v1 += ((p0 - p1) - v1) * 0.2`, `p1 += v1 * 0.25`.
2. **바람 자국 지도**: 64 × 40 격자(Float32, 가로 방향 세기). 매 프레임 `p1 → p0` 선분 위를 여러 번(최대 24) 찍어, 반지름 `화면 폭 × 0.08` 가우스 모양으로 **움직인 방향 × 속도**를 더함. 매 프레임 감쇠: 반감기 약 0.28초 (`keep = 0.5^(dt / (0.28 * decay))`), 값은 ±1.6으로 자름.
3. **식물마다 휨 계산 (CPU, 수백 개라 충분)**: 식물 끝 위치에서 지도를 읽어 `target = clamp(wind * gain * 0.32, -0.32, 0.32) + 살랑임`. 용수철로 따라감: `vel += (target - bend) * lag * 1.4; vel *= 0.78; bend += vel;` → `aBend`에 넣고 `needsUpdate = true`.
4. 살랑임(바람 없을 때): `sin(time*1.6 + phase + x*0.004) * 0.025`.
5. 바람 세기는 스크롤에 따라 줄임: `windAmt = max(0, 1 - progress * 1.6)`.
6. 터치 입력(`pointerType === 'touch'`)은 바람을 만들지 않음.

## 5. 스크롤 (장면 2 · 3)

- `progress` = 0(히어로) ~ 2(햇빛), `scrollY / innerHeight`를 0.12씩 부드럽게 따라가게.
- `s1 = smoothstep(progress)`, `s2 = smoothstep(progress - 1)`.
- 장면 전체 세로 이동: `offset = -shift * s1 + 2 * shift * s2` (shift 기본 26px) → 장면 2에서 살짝 아래, 장면 3에서 살짝 위.
- **흙 겹**: 실사 흙 단면 이미지(`soil.webp`, 가로로 이어 붙일 수 있게)를 화면 높이 83% 아래에 깔고 불투명도 `s1 * (1 - 0.85 * s2)`. 흙은 위치를 크게 옮기지 말고 **그 자리에서 나타나게** 할 것.
- **햇빛 겹**: 이미지 없이 셰이더(전체 화면 판)로. 오른쪽 위(화면 82%, -5%)에서 퍼지는 따뜻한 빛 `#FFF0AA → #F4D76B → 투명` + 아주 옅은 빛줄기. 배경도 `#FBFCF4`쪽으로 `s2`만큼 밝아짐.
  - **쨍하게 비쳤다가 옅어지기:** 장면 3에 들어오는 순간(progress가 1.6을 넘을 때) 한 번 번쩍.
    - 번쩍 값 `flash`: 0.12초 동안 0 → 1로 올라가고, 0.25초 동안 1로 머문 뒤, `exp(-(t - 0.37) / 0.6)`로 약 1.6초에 걸쳐 사라짐
    - 번쩍 화면 (식물 · 흙보다 **위에** 덮음, 스크롤 진행도와 상관없이 `flash` 값 그대로 적용):
      1. 화면 전체를 `rgba(255,253,238, 0.88·flash)`로 덮어 눈부시게 날림
      2. 오른쪽 위에서 퍼지는 뜨거운 빛 `rgba(255,255,255, flash) → rgba(255,250,215, 0.9·flash) → rgba(255,236,150, 0.45·flash) → 투명`
      3. 강한 빛줄기 9가닥 (가산 혼합, `rgba(255,240,170, 0.22·flash)`)
    - 번쩍이 끝난 뒤 남는 햇빛 세기는 `s2 × 0.6` (옅게 유지)
    - progress가 1.4 아래로 내려갔다가 다시 들어오면 또 번쩍. 동작 줄이기 설정에서는 번쩍 없이 옅은 햇빛만
- **자석 스크롤:** 휠 · 트랙패드를 멈추고 140ms가 지나면 가장 가까운 칸(0 · 1 · 2 × 화면 높이)으로 부드럽게 붙음 (`scrollTo({ behavior: 'smooth' })`, 붙는 중 650ms 동안은 다시 붙이지 않음). 3칸 밖(히어로 아래 섹션)에서는 붙이지 않음. 동작 줄이기 설정에서는 바로 이동.
- 기준 코드: `docs/reference/hero-demo.html`의 `drawFlash`, 스크롤 붙이기 부분.

### 7-1. 반복해서 깔기 (중요)

- **풀만이 아니라 모든 식물을 여러 번 반복해서** 화면을 채운다. 15장(14종 + 흙)으로 겹마다 60~150그루를 만들기 때문에, 한 이미지가 여러 번 나온다.
- 반복이 티 나지 않게, 그루마다 다르게 준다:
  - 크기 ±25%, 좌우 반전 50%, 기울기 ±4°, 밝기 · 색 아주 살짝(±6%)
  - 바로 옆에 같은 식물이 연달아 오지 않게 (이웃 2그루 안에서 같은 이미지 피하기)
  - 겹마다 식물 비율을 다르게: 뒤 겹은 풀 · 아스파라거스 · 올리브처럼 가는 식물 위주, 앞 겹은 몬스테라 · 칼라테아 · 극락조 · 필레아처럼 잎이 큰 식물 위주, 중간 겹은 골고루
- 극락조 · 몬스테라처럼 큰 잎은 앞 겹에서 너무 자주 나오지 않게(전체의 10% 안팎), 화면 가장자리 쪽에 더 많이.

## 8. 꼭 지킬 것

- `prefers-reduced-motion: reduce` 또는 터치 기기: 바람 · 살랑임 끔. 스크롤 장면은 겹이 바로 나타나는 정도만.
- WebGL을 못 쓰거나 이미지 로딩 실패: `hero-fallback.webp` 한 장 + 글 · 버튼은 그대로.
- 화면 밖으로 나가면 렌더 멈춤 (`IntersectionObserver`), 탭이 숨으면 멈춤.
- 컴포넌트가 사라질 때 geometry · material · texture · renderer 정리.
- 창 크기가 바뀌면 카메라 · 렌더러 · 식물 배치 다시 계산.
- 목표 성능: 데스크탑에서 60fps, 그리기 호출 6번 안팎.

## 9. 다 됐는지 확인

- [ ] 마우스를 빠르게 움직여도 바람 자국이 끊기지 않고, 지나간 뒤 약 1초 흔들림이 남는다
- [ ] 앞 겹이 가장 크게, 뒤 겹이 가장 작게 흔들린다. 밑동은 움직이지 않는다
- [ ] 한 칸 내리면 장면이 약 26px 아래로 가고 흙이 그 자리에서 나타난다. 바람은 잦아든다
- [ ] 한 칸 더 내리면 장면이 약 26px 위로 가고 오른쪽 위에서 햇빛이 밝아진다
- [ ] 제목 · 버튼은 처음부터 보이고, 식물에 가려 읽기 어려운 곳이 없다
- [ ] 동작 줄이기 설정, 터치 기기, WebGL 없음에서 각각 깨지지 않는다
- [ ] 이미지 가장자리에 흰 테두리가 보이지 않는다
- [ ] 콘솔 오류 없음
