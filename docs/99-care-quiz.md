## 1. 진단 방식

- **카드형 질문:** 모든 선택지는 **이미지 + 짧은 텍스트** 카드로 보여 줍니다. 초보자가 글보다 그림으로 쉽게 고를 수 있게 하기 위해서입니다.
- **단일 선택 질문:** 카드를 누르면 바로 다음 질문으로 넘어갑니다.
- **다중 선택 질문:** 증상, 벌레 질문은 여러 장을 고를 수 있습니다. 카드를 누르면 카드 자체가 선택 상태(테두리 강조)로 바뀌고, **[다음]** 버튼으로 넘어갑니다. 질문 아래 문구는 '해당되는 ~을 모두 골라보세요'로 통일합니다. (Q2 "해당되는 증상을 모두 골라보세요." / Q3 "해당되는 상황을 모두 골라보세요.")
- **체크 표시 없음:** 질문 카드 오른쪽 위에 따로 체크 표시(○ · □)를 두지 않습니다. 단일 · 다중 선택 모두 카드를 누르면 카드 자체가 선택 상태가 됩니다.
- **공통:** 상단에 진행 표시(예: 2 / 7), 이전 질문으로 돌아가는 버튼을 둡니다.
- **계절:** 접속한 날짜로 현재 계절을 자동으로 판단하고, 실제 온도 환경은 질문으로 확인합니다.
- **카드 이미지 종류:** 일러스트. 실사는 벌레 사진이 징그러울 수 있고, 아이콘은 뜻을 전하기 어려워서 일러스트로 정했습니다. 그림체는 추후 결정입니다.

## 2. 질문 구성 (3단계 · 7문항)

### 1단계 · 식물 종류

**Q1. 어떤 식물을 키우고 계세요?** (단일 선택)

| 카드 | 설명 문구 | 예시 식물 |
|---|---|---|
| 관엽식물 | 잎을 보며 키우는 초록 식물 | 몬스테라, 고무나무, 스킨답서스 |
| 다육·선인장 | 잎이나 줄기가 통통하고 물을 머금는 식물 | 에케베리아, 선인장, 산세베리아 |
| 꽃 피는 식물 | 꽃을 보기 위해 키우는 식물 | 안스리움, 제라늄, 스파티필름 |
| 허브 | 향이 나고 잎을 쓰기도 하는 식물 | 로즈마리, 바질, 민트 |
| 과실 식물 | 열매가 열리는 식물 | 레몬나무, 올리브나무, 블루베리 |
| 난초류 | 흙 대신 바크·수태에 심는 식물 | 호접란, 덴드로비움 |
| 잘 모르겠어요 | 관엽식물 기준으로 진행 | 결과에 "종류를 알면 더 정확해요" 안내 |

### 2단계 · 증상

**Q2. 요즘 식물이 어떤 신호를 보내나요?** (다중 선택)

| 묶음 | 카드 |
|---|---|
| 잎 색 | 잎이 노랗게 변해요 |
| | 아래쪽 잎부터 노래지며 떨어져요 |
| | 잎에 갈색·검은 반점이 생겼어요 |
| | 잎 끝이 갈색으로 바싹 말라요 |
| | 잎이 하얗게 바래거나 탄 자국이 있어요 |
| 잎·줄기 모양 | 잎이 축 처지고 힘이 없어요 |
| | 잎이 쭈글쭈글하고 얇아졌어요 |
| | 줄기만 길쭉하게 웃자라요 |
| | 새잎이 안 나거나 작게 나와요 |
| 뿌리·흙 | 줄기 밑동이 물러지고 냄새가 나요 |
| | 흙 위에 하얀 곰팡이가 생겼어요 |
| | 화분 밑 구멍으로 뿌리가 나와요 |
| 꽃·열매 | 꽃봉오리나 열매가 떨어져요 (꽃 피는 식물, 과실 식물만 표시) |
| 없음 | 딱히 문제는 없어요 (선택하면 다른 카드는 해제) |

**Q3. 혹시 이런 벌레가 보이나요?** (다중 선택)

카드에는 **방문자가 눈으로 보는 모습**을 쓰고, 벌레 이름은 결과에서 알려 줍니다.

| 카드 (보이는 모습) | 결과에서 알려 줄 벌레 |
|---|---|
| 작은 날파리가 화분 주변을 날아다녀요 | 뿌리파리 |
| 잎이나 줄기에 하얀 솜 같은 게 붙어 있어요 | 솜깍지벌레 |
| 줄기에 갈색 딱지가 붙어 있어요 | 깍지벌레 |
| 잎 뒷면에 거미줄과 아주 작은 점이 있어요 | 응애 |
| 새순에 작은 초록·검은 벌레가 모여 있어요 | 진딧물 |
| 잎에 은빛 긁힌 자국과 검은 점이 있어요 | 총채벌레 |
| 흙 위를 하얀 아주 작은 벌레가 톡톡 뛰어요 | 톡토기 |
| 벌레는 안 보여요 (선택하면 다른 카드는 해제) | — |

### 3단계 · 환경

**Q4. 식물이 있는 곳은 얼마나 밝나요?** (단일 선택)
- 해가 직접 드는 밝은 창가
- 밝지만 해가 직접 들지는 않아요
- 빛이 거의 안 들어요

**Q5. 물은 어떻게 주고 계세요?** (단일 선택)
- 흙이 마르기 전에 자주 줘요
- 겉흙이 마르면 줘요
- 깜빡해서 오래 못 줄 때가 많아요
- 잘 모르겠어요

**Q6. 식물이 있는 곳의 온도는 어떤가요?** (단일 선택, 화면에 자동 판단한 현재 계절 표시)
- 따뜻해요 (20℃ 이상)
- 선선해요 (10~20℃)
- 추워요 (10℃ 아래, 창가 냉기)
- 에어컨이나 난방 바람이 직접 닿아요

**Q7. 마지막 분갈이는 언제였나요?** (단일 선택)
- 1년 안에 했어요
- 1년이 넘었거나 한 적이 없어요
- 잘 모르겠어요

## 3. 답 → 결과 연결

### 원인 판단표

| 답 조합 | 원인 (결과 문구 방향) | 추천 흙 | 추천 영양제 | 케어 가이드 |
|---|---|---|---|---|
| 노란 잎·처짐·밑동 무름·흙 곰팡이 + 물 자주 | 물이 조금 많았어요. 뿌리가 쉴 틈이 필요해요 | 배수 잘 되는 흙 | 뿌리 활력제 | 물 주기, 분갈이 |
| 잎끝 마름·처짐·쭈글쭈글 + 물 오래 못 줌 | 목이 말랐던 것 같아요 | 종류별 기본 흙 | (없음) | 물 주기 |
| 웃자람·새잎 없음 + 빛 거의 없음 | 빛이 조금 부족해요 | (없음) | (없음) | 햇빛 |
| 하얗게 바램·탄 자국 + 직사광선 창가 | 햇빛이 조금 강했어요 | (없음) | (없음) | 햇빛 |
| 새잎 없음·아래 잎 노랗게 + 분갈이 1년 넘음 | 흙의 영양이 다 떨어졌어요 | 종류별 기본 흙 | 성장 영양제 | 분갈이 |
| 화분 밑 뿌리 나옴 | 화분이 작아졌어요. 새집이 필요해요 | 종류별 기본 흙 | 뿌리 활력제 | 분갈이 |
| 반점·잎끝 마름 + 추워요 / 바람 직접 닿음 | 온도 변화에 놀랐어요 | (없음) | (없음) | 계절별 관리 |
| 꽃봉오리·열매 떨어짐 | 환경이 바뀌었거나 영양이 부족해요 | (없음) | 개화·결실 영양제 | 햇빛, 계절별 관리 |
| 벌레 카드 선택 | 해당 벌레 이름과 대처법 (4번 표) | 뿌리파리면 배수 흙 | (없음) | 벌레 대처 (관리법만 안내, 벌레 관련 상품은 팔지 않음) |
| 문제 없음 + 벌레 없음 | 잘 키우고 계세요! | (없음) | 기본 영양제 | 현재 계절 팁 |

- **흙 종류:** Q1 답으로 정합니다. 관엽 → 관엽용 흙, 다육·선인장 → 다육용 흙, 꽃·허브 → 화초용 흙, 과실 → 과실수용 흙, 난초류 → 난초용 바크
- **여러 개 선택했을 때:** 원인을 모두 보여 주되, **"가장 먼저 할 일" 1가지**를 맨 위에 둡니다. 우선순위는 벌레·밑동 무름 → 물 → 온도 → 빛 → 영양 순입니다.
- **판매 압박 피하기:** 빛, 온도처럼 상품이 필요 없는 원인은 상품을 추천하지 않고 관리법만 보여 줍니다.
- **결과 말투:** 겁주지 않고 "괜찮아요, 이렇게 바꿔 볼게요" 같은 다정한 문장으로 씁니다.

## 4. 벌레 대처 정리

결과 화면과 케어 가이드에 함께 쓰는 내용입니다. **발견하면 먼저 다른 화분과 떨어뜨려 둡니다.** 익충은 설명에 따로 적어 두었고, 그대로 두어도 괜찮습니다.

| 벌레 | 보이는 모습 | 왜 생기나요 | 바로 할 일 | 심할 때 | 예방 |
|---|---|---|---|---|---|
| 뿌리파리 | 화분 주변을 나는 작은 날파리 | 늘 축축한 흙에 알을 낳아요 | 겉흙이 마를 때까지 물 주기 쉬기, 노란 끈끈이 트랩 꽂기 | 흙에 물처럼 주는 뿌리파리용 살충제 사용, 분갈이로 흙 교체 | 겉흙이 마른 뒤 물 주기, 겉흙을 마사토로 덮기 |
| 솜깍지벌레 | 잎·줄기 틈의 하얀 솜 뭉치 | 통풍이 안 되고 건조할 때 잘 생겨요 | 소독용 알코올을 묻힌 면봉으로 닦아 내기 | 식물 전체에 퍼지는 침투성 살충제 사용 | 잎 틈 자주 살피기, 통풍 |
| 깍지벌레 | 줄기에 붙은 갈색 딱지 | 통풍이 안 될 때 잘 생겨요 | 칫솔이나 손톱으로 긁어 내고 알코올로 닦기 | 침투성 살충제 사용 | 통풍, 새로 들인 식물은 2주 정도 따로 두기 |
| 응애 | 잎 뒷면의 거미줄, 아주 작은 점, 잎이 희끗해짐 | 덥고 건조할 때(특히 난방 철) 잘 생겨요 | 잎 앞뒤를 샤워기로 씻어 내기, 주변 습도 높이기 | 응애 전용 약제 사용 (일반 살충제는 잘 안 들어요) | 잎 뒷면에 물 뿌리기, 건조한 바람 피하기 |
| 진딧물 | 새순에 모인 작은 초록·검은 벌레 | 연한 새순의 즙을 좋아해요 | 물로 씻어 내거나 손으로 떼어 내기 | 식물용 비눗물·님오일 같은 친환경 약제, 그래도 남으면 살충제 | 새순 자주 살피기, 통풍 |
| 총채벌레 | 잎의 은빛 긁힌 자국과 검은 점 | 따뜻하고 건조할 때 잘 생겨요 | 잎을 샤워기로 씻기, 파란 끈끈이 트랩 걸기 | 총채벌레용 살충제를 일주일 간격으로 2~3번 | 통풍, 잎 자주 닦기 |
| 톡토기 | 흙 위를 톡톡 뛰는 하얀 작은 벌레 | 흙 속 찌꺼기를 분해하는 익충이에요. 흙이 축축할 때 많이 보여요 | 그대로 두어도 괜찮아요. 너무 많으면 물 주기 간격을 늘려 흙 말리기 | 필요 없음 | 과습 피하기 |

- **약제를 쓸 때:** 제품 라벨의 사용법과 양을 지키고, 환기가 되는 곳에서 사용합니다. 반려동물이나 아이가 닿지 않게 합니다.
- **결과 말투:** 벌레가 생기는 것은 식물을 키우다 보면 자연스러운 일이라는 점을 먼저 말하고, 관리해 주면 더 건강하게 키울 수 있다는 방향으로 씁니다. 경고나 걱정을 키우는 표현은 쓰지 않습니다.
  - 예시: "식물을 키우다 보면 벌레가 찾아오는 건 자연스러운 일이에요. 조금만 관리해 주면 더 건강하게 자랄 거예요."

## 6. DIY 흙 만들기

케어 제품 페이지에서 흙 재료를 골라 원하는 만큼 담으면, 섞은 흙이 어떤 기능을 하는지 결과가 바로 나옵니다. 체험 결과 화면에서도 "DIY 흙 담기" 버튼으로 들어올 수 있습니다.

### 담는 방법
- 재료도 **일러스트 카드**로 보여 줍니다.
- 재료 카드를 누를 때마다 **1스쿱씩** 담깁니다. 한 봉은 **6L**(상토 기준 약 3kg), 전체는 **10스쿱**이고, 1스쿱은 **0.6L(10%)**입니다.
- 재료마다 무게가 크게 달라서(펄라이트는 가볍고 마사토는 무거움) 비율은 **부피 기준**으로 계산합니다. 무게는 "약 3kg (상토 기준)"처럼 참고로만 보여 줍니다.
- 네모난 흙 봉투 일러스트에 재료가 층층이 쌓이는 모습으로 비율을 보여 주고(한 층 = 1스쿱, 봉투 옆에 스쿱 눈금 5 · 10), 담을 때마다 결과가 바로 바뀝니다.
- 담은 재료는 하나씩 빼거나 처음부터 다시 담을 수 있습니다.

### 재료

| 재료 | 역할 | 기능 묶음 |
|---|---|---|
| 상토(배양토) | 기본 흙. 영양과 보습을 함께 줘요 | 기본 |
| 부엽토 | 양분이 많아요 | 영양 |
| 코코피트 | 물을 오래 머금어요 | 보습 |
| 질석(버미큘라이트) | 물과 양분을 붙잡아 둬요 | 보습 |
| 펄라이트 | 흙 사이에 숨구멍을 만들어요 | 배수 |
| 마사토 | 물이 잘 빠지고 흙을 무겁게 잡아 줘요 | 배수 |
| 바크 | 굵은 나무 조각. 공기가 잘 통해요 | 배수·통기 |
| 훈탄 | 뿌리 썩음과 냄새를 줄여요 | 배수·통기 |

### 결과 판단 (먼저 맞는 것부터 적용)

| 배합 조건 | 결과 문구 | 어울리는 식물 |
|---|---|---|
| 바크 60% 이상 | 공기가 아주 잘 통해요. 난초용 흙에 적합해요 | 난초류 |
| 배수 재료(펄라이트·마사토·바크·훈탄) 60% 이상 | 물이 잘 빠져요. 배수용 흙에 적합해요 | 다육·선인장, 과습이 걱정되는 식물 |
| 보습 재료(코코피트·질석) 50% 이상 | 촉촉함을 오래 지켜요. 물을 좋아하는 식물에 적합해요 | 물을 좋아하는 관엽식물 |
| 상토+부엽토 60% 이상, 부엽토 20% 이상 | 영양이 풍부해요. 영양이 필요한 식물에 적합해요 | 꽃 피는 식물, 과실 식물 |
| 상토 50~70% + 배수 재료 30~50% | 영양과 배수가 균형 잡혀 있어요. 관엽식물 기본 흙에 적합해요 | 관엽식물, 허브 |
| 상토만 100% | 물이 오래 머물 수 있어요. 펄라이트를 조금 섞으면 더 좋아요 | 대부분의 식물 (배수 보완 권장) |
| 그 외 | 섞은 비율에 맞춰 배수·보습·영양 정도를 막대로 보여 줘요 | — |

- **결과 표시:** 결과 문구와 함께 **배수 / 보습 / 영양** 세 가지 정도를 막대로 보여 줍니다.
- **체험과 연결:** 체험을 마친 방문자라면 "내 식물(예: 다육·선인장)에 잘 맞아요" 또는 "배수 재료를 2스쿱 더 담아 보세요"처럼 내 식물 기준으로 알려 줍니다.
- **말투:** 틀린 배합이라고 하지 않고, 더 좋아지는 방법을 다정하게 제안합니다.
- **구매:** 담은 배합 그대로 구매 버튼을 보여 줍니다. 장바구니·결제는 추후 결정입니다.
