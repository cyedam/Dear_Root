# Dear Root 사이트 목적 정의

## 1. 사이트 목적 한 문장

> 잎이 보내는 신호를 읽고 뿌리부터 다시 돌보는 맞춤 케어, Dear Root 입니다.

- 사이트와 체험, 제품 이름에는 '처방' 대신 **'맞춤 케어'**라는 표현을 씁니다. (예: 맞춤 케어 체험, 케어 제품)

## 2. 주요 방문자와 방문자의 필요

### 주요 방문자
1. **초보 식집사**: 식물을 키운 지 얼마 안 됐고, 식물이 시들어도 이유를 몰라 헤매는 사람
2. **입문 고민층**: 식물을 선물받았거나 막 들였는데 어떻게 돌봐야 할지 모르는 사람
   - 다른 사람에게 선물하려고 오는 방문자(선물하는 사람)는 **포함하지 않습니다.**

### 방문자의 필요
| 필요 | 내용 | 채우는 곳 |
|---|---|---|
| 원인 알기 | 내 식물이 왜 시드는지, 지금 상태가 괜찮은지 | 맞춤 케어 체험 |
| 무엇을 사야 할지 | 내 식물에 맞는 흙과 영양제 | 맞춤 케어 체험 결과 |
| 돌보는 방법 | 물 주기, 햇빛, 분갈이 같은 관리 요령 | 별도 케어 가이드 |
| 안심과 확신 | 잘못하고 있는 게 아니고, 이대로 하면 살릴 수 있다는 믿음 | (사이트 전반의 인상) |

### 체험에서 다루는 식물 범위
- **실내 화분 전반** (관엽·다육 등 집에서 키우는 화분 식물)

## 3. 가장 중요한 행동과 보조적인 행동

### 가장 중요한 행동
- **맞춤 케어 체험을 끝까지 해서 내 식물의 케어 결과 받기**

### 보조적인 행동
- **케어 제품 구매**: 체험 결과로 나온 흙과 영양제 구매
  - 구매 방식: **세트 구매와 개별 구매를 모두** 할 수 있게 합니다.

## 4. 전달하고 싶은 인상과 피하고 싶은 방향

### 전달하고 싶은 인상
- **다정하고 편안함**: 몰라도 괜찮다, 같이 봐줄게요 하는 느낌

### 피하고 싶은 방향
- **겁주고 불안하게 함**: "이러다 죽어요" 같은 경고성 문구로 죄책감을 주는 느낌
- **과한 판매 압박**: 체험보다 구매 버튼과 할인 문구가 앞서는 느낌
- **차갑고 병원 같음**: 딱딱하고 의료적인 느낌

## 5. 기기 기준

- **주요 기기:** 데스크탑 기준으로 진행합니다.
- **반응형:** 다른 화면 크기에서도 볼 수 있도록 반응형으로 처리합니다.
